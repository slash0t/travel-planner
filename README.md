#### 🚀 Инструкция по установке
1. Скачайте APK файл по ссылке выше
2. Разрешите установку из неизвестных источников в настройках Android
3. Установите и запустите приложение
4. Зарегистрируйтесь или войдите в систему

> ⚠️ **Важно:** При публикации маршрута в библиотеку вы должны одобрить его публикацию через админ панель

---

*Путевод - это инновационная платформа для планирования и организации путешествий, которая помогает создавать незабываемые приключения.*
